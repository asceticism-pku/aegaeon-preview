# Join the Aegaeon Community

Aegaeon welcomes bug reports, feature proposals, and contributions. Help improve model integration, scheduling policies, performance tooling, or documentation, and share your deployment experience.

## Report an issue

When submitting [GitHub Issues](https://github.com/pkusys/aegaeon/issues), include:

- Expected behavior, actual behavior, and minimal reproduction steps.
- Startup commands, relevant configuration, and request parameters.
- Python, PyTorch, vLLM, CUDA, and driver versions.
- GPU model, execution mode, and the full traceback.

Remove access tokens, user inputs, and other sensitive information from configurations and logs. Performance reports also need actual token lengths, load conditions, warmup, and sample counts.

## Propose a feature

Describe the scenario, current behavior, and proposed interface. For new models, KV types, parallelism, or graph restoration, specify the target environment and a reproducible validation method.

## Contribute code or documentation

Read the [developer guide](development.md) for project layout and validation practices. Pull Requests should explain resulting user behavior, compatibility impact, and tests.

Documentation improvements are welcome: clearer examples, explanations, parameter corrections, and troubleshooting experience help others use Aegaeon.
