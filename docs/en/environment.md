# Environment Variables

This reference covers main variables read, forwarded, or generated by the source. Forwarding does not imply consumption, and internal settings are not stable public interfaces. Variables are mainly read at module import, service creation, or actor initialization; restart relevant processes after changes to keep settings consistent.

| Variable | Default / source | Meaning |
|---|---|---|
| `AEGAEON_LOG_FILE` | output.log | Read at logger import; LLMService explicitly forwards it to Controllers |
| `AEGAEON_TTFT_SLO` | 10 | Seconds; read at utils import, not in LLMService's explicit actor allowlist |
| `AEGAEON_TPOT_SLO` | 0.1 | Seconds; read at utils import, not in the explicit actor allowlist |
| `AEGAEON_DEFAULT_MODEL_REPO` | modelscope | modelscope or huggingface |
| `AEGAEON_SHM_DIR` | /dev/shm | Shared cache directory; requires capacity and isolation |
| `AEGAEON_RAY_ADDRESS` | RAY_ADDRESS / auto | Ray address; CLI takes precedence |
| `RAY_ADDRESS` | auto | Ray address fallback |
| `AEGAEON_RAY_TEMP_DIR` | Unset | Temporary directory for local Ray creation |
| `AEGAEON_ARENA_FRACTION` | 0.875 | QuickLoader GPU arena fraction; forwarded via runtime_env when create_service calls ray.init, with this step skipped if Ray is already initialized; arena size is also capped at GPU capacity minus 8 GiB |
| `AEGAEON_MAX_REQUESTS_PER_SECOND` | Unset | Per-model API limit using a 60-second window |
| `AEGAEON_MAX_TOKENS_PER_SECOND` | Unset | Recorded-token window-average rate cap; normal final results enter statistics; see monitoring for disconnect boundaries |
| `AEGAEON_GPU_FREQ_CONTROL` | false | Clock-control component flag; model YAML wiring is incomplete |
| `AEGAEON_GPU_CLOCK_COMMAND` | Unset | Clock-control wrapper command |
| `AEGAEON_NVIDIA_SMI_COMMAND` | Unset | Sampling/control command override |
| `AEGAEON_CUDA_COMPAT_PATH` | Probed default paths | Existing CUDA compatibility library directory |
| `AEGAEON_FOUNDRY_HOOK_PATH` | Unset | Existing absolute .so file path required by save/load Decode Workers |
| `AEGAEON_DUMMY_WEIGHTS` | Unset | 1 enables placeholder weights, not valid quality/performance results |
| `AEGAEON_CUDA_VISIBLE_DEVICES` | Unset | Controller/Worker visible device set |
| `CUDA_VISIBLE_DEVICES` | Process environment | Driver value converted into custom actor visibility |
| `AEGAEON_CONFIG_PATH` | Internally set | Service configuration path |
| `AEGAEON_CONFIG_CONTENT` | Internally set | Complete YAML content |
| `AEGAEON_SHAREGPT_PATH` | /root/ShareGPT_V3_unfiltered_cleaned_split.json | Workload-tool dataset, not an API prerequisite |
| `FAST_SWITCH` | Set to 1 by LLMService | Internal switching control, not a general user option |
| `SERVERLESSLLM_URL` | http://127.0.0.1:8343 | External demo proxy URL |
| `AEGAEON_MODEL_ROOT` | Unset | Forwarded to actors, not consumed by the main downloader |
| `AEGAEON_MODEL_ROOTS` | Unset | Same limitation; not a working model-search-root setting |
| `AEGAEON_MODEL_DOWNLOAD_PROXY` | Unset | Forwarded and used by profile scripts, not consumed by the main downloader |
| `LD_LIBRARY_PATH` | Environment | Library search paths; startup prepends a compatibility path when one is configured or found |
| `LD_PRELOAD` | Internally constructed | Foundry hook set before Worker startup |
| `PYTHONPATH` | Environment | Source/module search path forwarded to actors |
| `FOUNDRY_MODE` | Internally set | Derived from cuda_graph.mode |
| `FOUNDRY_EARLY_RESERVE_BASE` | Internally set | Derived from base_address |
| `FOUNDRY_EARLY_RESERVE_SIZE` | Internally set | Derived from region_size_bytes |
| `TORCH_CUBLASLT_UNIFIED_WORKSPACE` | Set to 1 on graph paths | Foundry unified workspace |
| `NCCL_ASYNC_ERROR_HANDLING` | Removed by Worker | Removed in Worker.initialize |
| `HTTP_PROXY` | Environment | Standard proxy setting forwarded to actors |
| `HTTPS_PROXY` | Environment | Same |
| `http_proxy` | Environment | Same |
| `https_proxy` | Environment | Same |

With a custom Boost prefix, Foundry also needs its `lib` directory in `LD_LIBRARY_PATH`; expose the Boost CMake configuration through `CMAKE_PREFIX_PATH` during the build. Environments that require CUDA forward-compatibility libraries must prepend the compat directory before importing Foundry directly. Worker startup prepends the explicit `AEGAEON_CUDA_COMPAT_PATH`, or probes the first existing directory among `/usr/local/cuda-<torch.version.cuda>/compat` and `~/.local/cuda-<torch.version.cuda>/compat`.

See configuration, deployment, power, and model guides for SLO consistency, visibility, clocks, and downloader restrictions. Ray variables such as RAY_DEDUP_LOGS are upstream diagnostics rather than Aegaeon performance features.
